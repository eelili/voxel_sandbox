# voxel_sandbox

### 安全与合规声明

**1. 完全独立自主开发**

本项目是一个从底层数学库、事件系统到网络通信协议均完全自主设计的沙盒游戏服务端工具。项目所有核心代码、架构设计均源自独立开发，旨在为体素沙盒场景提供纯粹的技术服务方案。

**2. 去中心化运行模式**

本工具仅提供可本地部署、自托管运行的服务器程序（Server-side Application）。项目不依赖任何第三方云服务、中心化平台或在线账户体系，亦不会主动收集、存储或上传用户的任何隐私数据。所有地图数据、配置文件和运行状态均由使用者完全掌控，并存储于本地环境。
